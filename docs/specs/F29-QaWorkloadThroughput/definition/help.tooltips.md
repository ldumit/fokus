# QA Workload & Throughput — Tooltips

## Total TEs Card

Number of test executions linked to sprint tickets. Counts unique TEs, not individual test runs.

## Total Runs Completed Card

Total individual test runs with a final result (pass or fail) across all testers this sprint.

## Team Pass Rate Card

Percentage of completed test runs that passed. Only counts runs with a final pass or fail result.

## Workload Distribution Chart

Shows how test execution volume is split across team members, broken down by pass and fail results.

## Execution Throughput Trend Chart

Each person's completed test runs per sprint over time. Helps spot changes in testing capacity.

## TEs Owned Column

Test executions assigned to this person. Counts ownership regardless of who ran the individual tests.

## Runs Completed Column

Test runs this person executed with a final pass or fail result. Attributed by who ran the test.

## Pass Column

Number of test runs this person executed that passed.

## Fail Column

Number of test runs this person executed that failed.

## Pass Rate Column

Percentage of this person's completed runs that passed. Color indicates quality against thresholds.

## Stories Covered Column

Unique sprint tickets linked to test executions where this person ran at least one test.

## Bugs Found Column

Bugs discovered through test executions this person owns. Credit goes to the TE owner.

## Workload Balance Flag

Flags when one person handles over 50% of all test executions for two or more consecutive sprints.
