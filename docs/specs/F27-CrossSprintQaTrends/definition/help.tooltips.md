# Cross-Sprint QA Trends — Tooltips

## Quality Trends Chart

Shows coverage rate, pass rate, and execution rate across sprints. Reveals whether testing quality is improving over time.

## Coverage Rate Line

% of feature tickets with at least one linked test execution. Higher means more stories are being tested.

## Pass Rate Line

% of test runs that passed out of all completed runs. Higher means tests are passing more consistently.

## Execution Rate Line

% of covered tickets where test executions have completed runs. Higher means testing is keeping pace.

## Testing Volume Chart

Total test executions and bugs found per sprint. Shows whether testing effort is growing or shrinking.

## TE Count

Number of test execution issues linked to sprint tickets. More TEs generally means broader testing effort.

## Bugs Found

Unique bugs discovered through test executions in each sprint. Catching more bugs during testing is better than in production.

## Defect Correlation

Compares test coverage in one sprint against the bug ratio in the next sprint (N+1 lag). Lower coverage often predicts more bugs.

## Pearson r Badge

Correlation strength between coverage and next-sprint bugs. Negative = higher coverage predicts fewer bugs (healthy).
