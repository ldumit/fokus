# Xray Integration — Tooltips

## Xray Integration Toggle

Enable to connect Fokus with Xray Cloud for test coverage and execution data.

## Xray Client ID

Your Xray API Client ID from Xray Global Settings > API Keys.

## Xray Client Secret

Your Xray API Client Secret from Xray Global Settings > API Keys.

## Test Connection

Verifies your Xray credentials and confirms Fokus can access test data.

## Sync QA Data

Fetches latest test execution results from Xray for selected sprints.
