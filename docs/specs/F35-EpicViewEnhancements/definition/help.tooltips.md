# Epic View Enhancements — Tooltips

## Search Field

Filter epics by name or Jira key. Combines with the sub-team filter.

## Sort Indicator

Click any column header to sort. Click again to reverse direction.

## Column Visibility Toggle

Choose which columns to show or hide. Your selection is saved for next time.

## Started

Date when the first ticket in this epic began active work (passed the cycle time start boundary).

## Last Work

Date of the most recent active work on any ticket in this epic.

## Sticky Epic Column

The epic name stays visible as you scroll right through the table columns.
