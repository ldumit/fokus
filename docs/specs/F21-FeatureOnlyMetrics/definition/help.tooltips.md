# Feature-Only Delivery Metrics — Tooltips

## SP Completed Card

Feature story points completed this sprint. Bug SP shown separately below.

## Bug SP Annotation

Bug story points completed this sprint. Tracked separately from feature delivery.

## Completion %

Feature SP completed as a percentage of feature SP committed. Excludes bugs.

## Burnup Chart — Scope SP Line

Cumulative feature scope over sprint days. Excludes bug tickets.

## Burnup Chart — Completed SP Line

Cumulative feature SP completed over sprint days. Excludes bug tickets.

## Burnup Chart — Bug SP Area

Remaining bug SP per day. Grows when bugs are added, shrinks when resolved.

## Developer Throughput — SP Assigned

Feature story points assigned to this developer. Excludes bug tickets.

## Developer Throughput — SP Completed

Feature story points completed by this developer. Excludes bug tickets.

## Developer Throughput — Completion %

Feature SP completed as a percentage of feature SP assigned. Excludes bugs.

## Developer Throughput — Tickets Done

Feature tickets completed by this developer. Bug tickets excluded.

## Developer Throughput — Tickets Carried Over

Feature tickets not completed this sprint. Bug tickets excluded.
