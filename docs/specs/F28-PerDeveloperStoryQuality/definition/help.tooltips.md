# Per-Developer Story Quality — Tooltips

## Stories
Total feature stories assigned to this developer in the sprint scope.

## Covered
Stories with at least one linked test execution.

## Coverage %
Percentage of this developer's stories that have linked test executions.

## Pass Rate %
Percentage of test runs that passed across all test executions on this developer's stories.

## Untested
Stories with no linked test executions — the coverage gap for this developer.

## Bugs Found
Bugs discovered during testing of this developer's stories. Delta is neutral — more is not inherently good or bad.

## Below Median Warning
Coverage below team median for N consecutive sprints. Review in retro.

## Coverage % Trend Chart
Coverage % per developer across sprints. Shows whether story test coverage is improving.
