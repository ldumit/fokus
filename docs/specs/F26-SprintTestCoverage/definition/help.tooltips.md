# F26 — Sprint Test Coverage: Tooltips

Tooltip text for each UI element. Max 150 characters each. Shown on info icon hover.

---

## Coverage Rate

Percentage of feature tickets with at least one linked test execution. Higher means broader test protection.

## Execution Rate

Of covered tickets, percentage where tests have been run to completion (PASS or FAIL verdict).

## Pass Rate

Percentage of executed test runs that passed, across all test executions in this sprint.

## Bugs Found

Bugs discovered through test execution (linked via "Blocks" in Jira). Counts unique bugs only.

## Untested Tickets

Feature tickets with no linked test executions. Sorted by story points — highest risk first.

## Failing Tickets

Feature tickets where at least one test execution has a failing test run. Shows fail/total counts.

## Quality Sub-Score

Weighted combination of Coverage Rate and Pass Rate scores. Weights are configurable in Settings.

## Quality Health Weight

How much Quality contributes to the health score. Additive to delivery weights. Set 0 to observe without affecting score.

## Coverage Rate Thresholds

Green/amber thresholds for Coverage Rate card coloring. Default: green ≥ 80%, amber ≥ 50%.

## Execution Rate Thresholds

Green/amber thresholds for Execution Rate card coloring. Default: green ≥ 80%, amber ≥ 50%.

## Pass Rate Thresholds

Green/amber thresholds for Pass Rate card coloring. Default: green ≥ 90%, amber ≥ 70%.

## Coverage / Pass Rate Weights

How Coverage Rate and Pass Rate combine within the Quality sub-score. Default: 50/50. Minimum 1 each.
