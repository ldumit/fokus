# Epic Test Health — Tooltips

## Average Test Coverage Card
Arithmetic mean of test coverage rates across visible epics. Excludes epics with zero feature tickets.

## Coverage % Column
Percentage of feature tickets in this epic that have at least one linked Test Execution. Bugs are excluded from the count.

## Pass Rate % Column
Percentage of PASS test runs out of all completed (PASS + FAIL) runs across this epic's linked Test Executions.

## Bugs Found Column
Unique bug tickets discovered through Test Executions linked to this epic's feature tickets.

## Coverage Progress Bar
Test coverage of this epic's feature tickets. Compare against the SP completion bar above for a delivery-vs-quality view.

## Test Status Badge
Ticket test status from linked Test Executions: Passed (all runs pass), Failed (any run fails), In Progress (tests incomplete), No Tests (no linked TEs).

## Ticket Pass Rate
Percentage of PASS test runs out of all completed runs for this ticket's linked Test Executions.

## Ticket Bugs Found
Bugs discovered through Test Executions linked to this ticket.
