# Carry-Over Tracker — Tooltip Help Content

Tooltip text for info icon hover in the carry-over sections on the Sprints page.

---

## Carry-Over Rate

Percentage of total sprint work (committed + added) not completed by sprint end.

## Carry-Over SP

Total story points on tickets not completed by sprint end.

## Carry-Over Ticket Count

Number of tickets not completed by sprint end.

## Carry-Over Rate Trend

How carry-over rate changes across sprints — a rising line signals growing delivery problems.

## Carry-Over by Workflow Stage

Where unfinished work is stuck — which workflow phase accumulates the most carry-over.

## Status Distribution (Donut Chart)

Proportional breakdown of where carry-over tickets are stuck by workflow phase.

## Issue Type Breakdown

Carry-over ticket counts by work type — stories, bugs, tasks, improvements, etc.

## Carry-Over Destination

What happened to the prior sprint's unfinished tickets — completed, carried again, removed, or dropped.

## Zombie Tickets

Tickets that have lived through 3 or more sprints without being completed.

## Zombie Trajectory

Sprint-by-sprint status history showing how a zombie ticket moved (or didn't) through workflow stages.

## Average Carry-Over Rate (Multi-Sprint)

The mean carry-over rate across the selected sprints.

## Total Zombie Tickets (Multi-Sprint)

Count of tickets appearing in 3 or more sprints within the selected range.
