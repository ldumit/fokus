# Leaderboard Breakdown — Tooltip Help

Sibling of `docs/features/LeaderboardBreakdown/spec.md`. Each section provides the Short variant (tooltip text, under 150 chars, shown on info icon hover).

---

## Features / Bugs Toggle

Switch between feature work and bug fix rankings. Features shows planned delivery; Bugs shows rework.

---

## Dashboard Leaderboard — Features Mode

Active developers ranked by feature story points completed this sprint. Bug fixes excluded.

---

## Dashboard Leaderboard — Bugs Mode

Active developers ranked by bug fix story points completed this sprint. Feature work excluded.

---

## Leaderboard SP Column

Story points completed for the selected work type. Excludes unestimated tickets.

---

## Leaderboard Tickets Column

Number of done tickets for the selected work type. Includes tickets with no story points.

---

## Leaderboard Tab (Developers Page)

Feature vs bug work composition per developer. Stacked bars show where sprint capacity went.

---

## Stacked Bar Chart

Blue segments are feature SP; red segments are bug SP. Sorted by total SP descending.

---

## Leaderboard Table — Feature SP

Story points completed on non-bug tickets across the selected sprints.

---

## Leaderboard Table — Bug SP

Story points completed on bug tickets across the selected sprints.

---

## Leaderboard Table — Total SP

Combined feature and bug story points completed across the selected sprints.

---

## Leaderboard Table — Feature Tickets

Number of completed non-bug tickets. Includes tickets with no story point estimate.

---

## Leaderboard Table — Bug Tickets

Number of completed bug tickets. Includes tickets with no story point estimate.

---

## Leaderboard Delta Indicators

Change versus the prior sprint. Feature SP: higher is green. Bug SP: lower is green. Total SP: neutral.

---

## Leaderboard Table — Total Tickets

Total completed tickets (features + bugs) across the selected sprints. Includes unestimated tickets.
