# Boundary-Driven Completion — Tooltips

## SP Completed

Story points completed this sprint — tickets that reached the cycle time end stage or beyond.

## Completion %

Feature SP completed divided by feature SP committed. Completion boundary set in Settings.

## Completed SP (Bar Chart)

Total story points (features + bugs) that reached the cycle time end stage or beyond.

## Completed SP (Burnup)

Feature story points that reached the cycle time end stage or beyond, per day.

## Carry-Over Rate

Percentage of scope not completed — tickets that did not reach the cycle time end stage.

## Cycle Time End Stage

The workflow stage that defines "completed." Tickets at or past this stage count as done.
