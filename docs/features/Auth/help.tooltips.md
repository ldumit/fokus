# Auth — Tooltips

## Sign in with Google
Authenticate with your company Google account to access Fokus.

## User Management
Invite new users, manage roles, and control access to Fokus.

## Invite Email
Enter the email address of the person you want to invite. Must be a company domain email.

## Invite Link
Share this link with the invited person. They'll sign in with Google to activate their account. Expires in 7 days.

## Role: Admin
Full access. Can modify settings, invite users, and manage roles.

## Role: Manager
View access to all data and settings. Cannot modify settings or manage users.

## Pending Invitations
Invitations waiting to be accepted. They expire automatically after 7 days.

## Deactivate User
Block this user from accessing Fokus. Their data is preserved and access can be restored later.

## Reactivate User
Restore access for a previously deactivated user.

## Settings (Read-Only)
View only — contact an Admin to make changes.

## Company Domain
Only Google accounts from this domain can access Fokus. Set automatically when the first user signs in.
