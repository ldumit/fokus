# Cycle Time — Tooltips

## Median Cycle Time Card
Half of completed tickets finish faster than this. Lower means the team is moving quicker.

## P85 Cycle Time Card
85% of tickets complete within this many days. Use this number for stakeholder commitments.

## Throughput Card
Number of tickets that completed the full workflow cycle this sprint.

## Outliers Card
Tickets taking more than 2x the sprint median. Investigate root causes in retrospectives.

## Scatter Plot
Each dot is one completed ticket. Higher dots took longer. Color indicates issue type.

## P50 Reference Line
Median cycle time. Half of tickets finish below this line, half above.

## P85 Reference Line
85th percentile. 85% of tickets finish below this line. Your predictability benchmark.

## Percentile Toggle
Switch which percentile is highlighted (single-sprint view only). P85 is recommended for commitments.

## Rework Badge
This ticket re-entered a workflow stage it had already passed through. The number shows re-entry count.

## Stage Funnel
Average time spent in each workflow stage. The widest bar is the team's bottleneck.

## Issue Type Breakdown
Cycle time comparison across issue types. Bugs are typically faster than stories.

## Per-Developer Breakdown
Cycle time patterns by developer. For identifying coaching opportunities, not ranking.

## Dominant Stage
The workflow stage where this developer's tickets spend the most time on average.

## Outlier Table
Tickets that took 2x+ the sprint median. Review these for process improvement insights.

## P85 Trend Line
Sprint-over-sprint P85 cycle time. A downward trend means the team is getting faster.

## Sprint Summary Table
One row per sprint with key cycle time metrics. Click a row to see full detail.

## Cycle Starts At (Settings)
Which workflow stage starts the cycle time clock. Default: first active work stage.

## Cycle Ends At (Settings)
Which workflow stage stops the cycle time clock. Default: first done status.
