# Normalized Capacity Indicator — Help

## Normalized SP Value (~X)

When a developer has reduced capacity for a sprint (vacation, part-time, tech lead duties), their raw SP completed will naturally be lower than full-time peers. The bracketed value (~X) shows an estimate of what their output projects to at 100% capacity, calculated by dividing their actual SP by their capacity percentage. Use this to compare developers fairly regardless of availability differences. The raw number (before the bracket) remains the real planning input — it's what you'll actually get from this person next sprint at the same capacity.

## No Bracket Shown

Developers at 100% capacity show only their raw SP completed. Since they're already at full availability, normalization would produce the same number — so it's hidden to keep the interface clean.
