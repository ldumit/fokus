# Bug Ratio — Tooltip Help Content

Sibling of `docs/features/BugRatio/spec.md`. Each section contains the **Short** variant — tooltip text shown on info icon hover (under 150 chars).

---

## Team Bug Ratio %

Percentage of completed story points spent on bug fixes vs. all completed work across the selected sprints.

---

## Bug SP / Non-Bug SP

Story points completed on bug-type tickets vs. all other ticket types (stories, tasks, sub-tasks).

---

## Bug Ratio Trend Chart

Bug ratio percentage per sprint over time. Spot sustained increases before they become the norm.

---

## Per-Developer Stacked Bar Chart

Bug SP (red) vs. Non-Bug SP (blue) per sprint for each developer. Compare allocation patterns.

---

## Per-Developer Table

Bug and non-bug SP, ticket counts, bug ratio %, and alert status for each active developer.

---

## Alert Badge

Appears when a developer's bug ratio exceeds the threshold for consecutive sprints.

---

## Issue Type Breakdown

Completed ticket counts grouped by raw Jira issue type. See composition beyond the bug/non-bug split.

---

## Sub-Team Filter

Restrict all bug ratio content to developers in the selected sub-team.

---

## Sprint Selector

Choose a single sprint for detail view, or a range (Last 3/5/All) for trend analysis.

---

## Bug Ratio Alert Settings

Configure when the bug ratio alert triggers: threshold percentage and consecutive sprint count.
