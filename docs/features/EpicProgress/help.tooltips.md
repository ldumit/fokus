# Epic Progress — Tooltip Help Content

Sibling of `docs/features/EpicProgress/spec.md`. Each section provides the Short variant (tooltip text, under 150 chars, shown on info icon hover).

---

## Summary Cards

### Active Epics

Number of epics with remaining work.

### Average Completion

Mean SP completion across all active epics.

### Unlinked Work

Tickets in sprints that aren't tied to any epic.

---

## Epic Table

### Progress Bar

SP completion with estimated portion shown separately.

### SP Done / SP Total

Completed story points versus total scope including estimates.

### Tickets Done / Total

Completed tickets versus total ticket count in the epic.

### Velocity

Average SP completed per sprint (last 3 sprints with progress).

### Projected Remaining

Estimated sprints to completion based on current velocity.

### Active Sprint Count

Number of sprints this epic has had tickets in.

---

## Expanded Ticket Table

### Ticket Row

Individual ticket details within the epic.

---

## Active / Completed Toggle

Switch between in-progress and finished epics.

---

## Sub-Team Filter

Scope all metrics to one sub-team's contributions.
