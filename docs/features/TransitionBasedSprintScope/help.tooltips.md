# Transition-Based Sprint Scope — Tooltips

## Committed SP (Active)

Feature story points started this sprint — tickets that first transitioned to the cycle time start stage during this sprint.

## Committed SP (Total)

Active plus removed feature story points. Shows total feature scope the sprint engaged with.

## Added SP

Feature story points added mid-sprint that entered the development pipeline (transitioned to the cycle time start stage).

## Completed SP

Feature story points that first reached the cycle time end stage during this sprint. Includes carry-over from previous sprints.

## Carry-Over Rate

Percentage of active scope not completed — tickets started this sprint that did not reach the cycle time end stage.

## Disruption Rate

Added feature SP divided by committed feature SP. Only counts added tickets that entered the cycle.

## Bug SP (Bar Chart)

Bug story points completed this sprint, shown separately from feature bars.

## Scope Line (Burnup)

Cumulative feature story points that entered the development pipeline (reached the cycle time start stage), per day.

## Completed Line (Burnup)

Cumulative feature story points that reached the cycle time end stage, per day.
